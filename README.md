# Time pessoal

Repositório para organizar os assuntos de cunho pessoal do titular e manter a página institucional do aplicativo Time pessoal.

## Organização pessoal

- [Caixa de entrada](pessoal/entrada.md): registrar assuntos antes de classificá-los.
- [Frentes pessoais](pessoal/README.md): áreas de acompanhamento e seus registros.

As prioridades serão definidas em uma próxima etapa. As áreas iniciais são uma proposta de organização; não indicam compromissos ou projetos já existentes.

## Página do aplicativo

- `index.html`: apresentação do aplicativo de uso particular.
- `privacidade.html`: política de privacidade.
- `estilo.css`: estilos da página.

## Uso dos registros

Cada assunto pode conter contexto, resultado desejado, situação e próximo passo. Datas, responsáveis e prioridades só devem ser registrados quando definidos.

Antes de incluir informações pessoais, conferir a visibilidade do repositório e eventual publicação por GitHub Pages. Usar descrições gerais e referências a documentos guardados em local adequado; não registrar senhas, tokens, documentos de identificação ou dados financeiros e de saúde sensíveis.
